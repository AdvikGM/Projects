What is Coding?

Coding is like a recipe. You give the computer steps and it follows them exactly.

The 3 Main Jobs of Code:

1. Remembering Things (Variables)

Computers store information like names or scores.

Example: score = 100

2. Making Decisions (If/Else)

Code tells the computer what to do when something happens.

Example: If it rains, show umbrella.

3. Repeating Tasks (Loops)

Code can repeat actions without getting tired.

Example: Send message to 50 friends.
